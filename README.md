# 가츠 위캣4(GUTS WECAT4) Vial 펌웨어

가츠 위캣4 40% 키보드(WB32FQ95, 44키, 유선·블루투스·2.4G)용 **비공식** QMK/Vial 펌웨어입니다.
이 펌웨어를 넣으면 [Vial](https://get.vial.today/)에서 키 배치·레이어·매크로·탭댄스·콤보·조명을 바로 바꿀 수 있고, 바뀐 내용은 키보드에 저장됩니다.

> **베타** — 유선·블루투스·Vial은 실사용으로 확인했고, 2.4G·배터리·충전 표시 등 ⚠️ 항목은 아직 실기 확인 전입니다. 확인 목록: [docs/VERIFY.md](docs/VERIFY.md)

> **주의**
> - 제조사·판매사의 공식 펌웨어가 아닙니다. 사용에 따른 책임은 사용자에게 있습니다(GPL-2.0 무보증).
> - 공개된 원래 펌웨어 파일이 없습니다. 이 펌웨어를 넣은 뒤 원래 펌웨어로 되돌리려면 판매사에 원본 파일을 요청해야 합니다.
> - 펌웨어를 넣으면 지금 저장된 키 배치가 지워집니다. VIA를 쓰고 있었다면 먼저 VIA에서 키맵을 저장해 두세요.

## 기능

| 기능 | 상태 |
|---|---|
| Vial 실시간 키 편집(8레이어, 매크로, 탭댄스, 콤보, 키 오버라이드, Caps Word, 조명) | ✅ |
| 유선(USB) | ✅ |
| 블루투스 3채널(BT1~3), 3초 = 새 페어링 | ✅ |
| 2.4G 동글 | ⚠️ 아직 실기 확인 전 |
| 배터리 잔량 표시, 충전 상태 표시, 초절전, 3초 공장 초기화 | ⚠️ 아직 실기 확인 전 |
| 5분 미사용 백라이트 끔, 30분 미사용 수면(무선) | ⚠️ 설정만 함, 실기 확인 전 |

무선 기능은 키보드 제조사(Hangsheng)가 공개한 무선 모듈 라이브러리를 그대로 써서 동작합니다. 자세한 내용은 [NOTICE.md](NOTICE.md)를 보세요.

## 두 가지 버전

| | `vial` (일반) | `dogakey` |
|---|---|---|
| 대상 | 원래 펌웨어에 가까운 표준 동작 | 아래 기능을 더 쓰고 싶은 사람 |
| 키 배치·Vial·무선·RAINBOW | 같음 | 같음 |
| 상태 강조 | — | ✅ |
| 언어 전환 번쩍임 | — | ✅ |
| 디바운스 | 표준 defer 5ms | eager 30ms(누르는 즉시 입력) |

### dogakey 버전의 기능

**상태 강조** — 레이어 키나 Shift·Ctrl·Win(Cmd)을 누르고 있는 동안, 그 상태에서 쓸 수 있는 키만 켜고 나머지는 끕니다. 레이어를 바꿨을 때 어떤 키를 눌러야 하는지 바로 보입니다. Vial에서 키를 옮기면 다시 굽지 않아도 그대로 반영됩니다.

| 누르고 있는 키 | 켜지는 키 | 색 |
|---|---|---|
| 레이어 1 | 그 레이어에 배정된 키 | 파랑 |
| 레이어 2 | 그 레이어에 배정된 키 | 흰색 |
| 레이어 3 이상 | 그 레이어에 배정된 키 | 보라 |
| Ctrl / Win(Cmd) | 공통 단축키(A C V X Z Y S F N T W R P Tab ← →) | 하늘색 |
| Shift | Shift로 결과가 바뀌는 키(글자·숫자·기호) | 주황빛 노랑 |

여러 개를 함께 누르면 레이어 > Ctrl/Win > Shift 순서로 보여 줍니다. Alt는 강조하지 않습니다. 키보드는 OS를 모르므로 Ctrl과 Win(Cmd)을 같게 봅니다.

**언어 전환 번쩍임** — 언어 전환 키를 누르면 키보드 전체가 초록으로 부드럽게 밝아졌다가, 연한 하늘색 띠가 왼쪽에서 오른쪽으로 흐르며 초록을 밀어내고 원래 조명으로 돌아옵니다(약 1.5초). 화면을 보면서도 눈 아래에서 전환한 것을 알 수 있습니다.
- 반응하는 키: CapsLock, 오른쪽 Alt, Lang1(한/영)·Lang2(한자), 일본어 かな·変換·無変換.
  macOS(CapsLock으로 입력 소스 전환), Windows 한국어 입력기(오른쪽 Alt), 한국어·일본어 전용 키를 기준으로 했습니다.
- 키보드는 지금 어떤 언어인지 모르므로 "전환 키를 눌렀다"만 알려 줍니다. 컴퓨터로 보내는 키는 그대로입니다.
- macOS에서 오른쪽 Option을 눌러도 번쩍입니다. Win+Space·Ctrl+Space 같은 조합과 중국어 입력기의 Shift 단독은 다른 용도와 겹쳐서 반응하지 않습니다.
- 반응할 키는 `keymaps/dogakey/highlight.c`의 `is_lang_switch()`에서, 시간과 색은 같은 파일 위쪽 `FLASH_*`·`SWEEP_*` 값에서 바꿀 수 있습니다.
- 조명을 꺼 두었으면 번쩍이지 않습니다. 배터리·충전·블루투스 연결 표시는 번쩍임보다 먼저 보입니다.

**eager 디바운스 30ms** — 누르는 순간 바로 입력하고, 그 뒤 30ms 동안 같은 키의 접점 떨림을 무시합니다. 입력 지연은 값과 상관없이 거의 0이라 게임에 유리하고, 접점이 떨리는 스위치의 중복 입력도 거릅니다.
- 대가: 같은 키를 떼고 30ms 안에 다시 누르면 보류됩니다(한 키 연타 상한 약 16회/초). 사람의 빠른 연타는 보통 7~12회/초라 거의 걸리지 않습니다.
- 버튼을 뗄 때 동작하는 게임 기술(네거티브 엣지)은 아주 짧게 친 경우 최대 30ms 늦을 수 있습니다. 더 짧게 쓰려면 `keymaps/dogakey/config.h`의 `DEBOUNCE`를 낮춰 직접 빌드하세요(20ms면 연타 상한 약 25회/초, 대신 20~30ms 대 떨림은 거르지 못함).

## 기본 키 배치

레이어 0은 키캡 각인 그대로입니다. **Fn**은 아래 줄 가운데(두 Space 사이) 키입니다.

| Fn + 키 | 동작 | Fn + 키 | 동작 |
|---|---|---|---|
| Tab | Esc | Q ~ P | 1 ~ 0 |
| Backspace | 배터리 잔량(Q~P 불빛, 10%당 1칸) | Enter | 초절전(무선) / 조명 끔(유선) |
| A / S / D | 블루투스 1 / 2 / 3 | F | 2.4G |
| K / L | `-` / `=` | `/` | `` ` `` |
| `.` / App / 오른쪽 Alt / 오른쪽 Ctrl | ↑ / ↓ / ← / → | 오른쪽 Space | 충전 상태(빨강 충전 중, 초록 완료) |
| Z | 조명 효과 바꾸기 | X / C | 조명 속도 − / + |
| B / M | 색상 − / + | N / H | 밝기 − / + |
| J / G | 채도 − / + | Win | Win 키 잠금 |
| 왼쪽 Ctrl **3초** | 공장 초기화 | | |

레이어 2~7은 비어 있습니다. Vial에서 원하는 대로 채우면 됩니다.
설명서의 Fn + 오른쪽 Shift(Windows/Mac 전환)는 원래 동작을 확인하지 못해 비워 두었습니다. 필요하면 Vial에서 `AG_TOGG`(Alt↔Win 교환) 같은 키를 넣으세요.

### Vial 전용 키

Vial의 **User** 탭에 있습니다. 원하는 자리에 넣어 쓸 수 있습니다.

| 이름 | 동작 |
|---|---|
| BT1 / BT2 / BT3 | 블루투스 채널 전환. 3초 누르면 그 채널로 새 페어링 |
| 2.4G | 2.4G 재연결. 3초 누르면 동글 페어링 |
| BAT | 배터리 잔량 표시 |
| CHRG | 충전 상태 표시 |
| SLEEP | 초절전 |
| RESET | 3초 누르면 공장 초기화 |
| RAINBOW | 조명을 무지개(Cycle Left/Right) 효과로 바로 전환 |

BT4·BT5·USB 키는 쓰지 않습니다(블루투스는 3채널, 유선은 옆면 스위치로 고릅니다).

## 무선 사용법

- 연결 방식은 **옆면 3단 스위치**로 고릅니다(BT / 유선 / 2.4G). 케이블을 꽂아도 자동으로 바뀌지 않습니다.
- **블루투스 처음 연결**: 스위치를 BT에 두고 Fn + A(또는 S, D)를 **3초** 누릅니다. 키가 빠르게 깜박이면 컴퓨터·휴대폰의 블루투스 목록에서 `WECAT4 BT1`(BT2, BT3)을 고릅니다.
- **기기 바꾸기**: Fn + A / S / D를 **짧게** 누릅니다. 3초를 누를 때마다 새 페어링이 만들어지므로, 이미 연결한 기기에서는 짧게 누르세요. 다시 페어링해야 한다면 기기 쪽의 예전 `WECAT4` 항목을 먼저 지우세요.
- **연결 표시**: 연결을 시도하는 동안 A·S·D 중 해당 키가 깜박입니다. 10초 안에 연결되지 않으면 키보드 전체가 어두운 빨강으로 깜박입니다. 연결되면 해당 키가 1초 켜졌다가 평소 조명으로 돌아갑니다.
- **2.4G**: 동글을 꽂고 스위치를 2.4G에 둔 뒤 Fn + F를 3초 누릅니다.
- **배터리 부족**: 무선 모드에서 잔량이 20% 이하이면 Fn 키가 빨갛게 깜박입니다.

## Vial로 키 바꾸기

1. 스위치를 **유선**에 두고 USB 케이블로 연결합니다. Vial은 유선에서만 연결됩니다.
2. [Vial 앱](https://get.vial.today/)을 실행하거나, Chrome·Edge에서 [vial.rocks](https://vial.rocks/)를 엽니다. 키보드 정의는 펌웨어에 들어 있어서 따로 불러올 파일이 없습니다.
3. 키를 누르고 아래 목록에서 바꿀 키를 고르면 바로 저장됩니다.
4. 매크로·부트로더 진입 같은 보안 항목을 바꾸라는 안내가 나오면, **Tab과 Backspace를 함께** 누르고 있어 잠금을 풉니다.

## 펌웨어 넣기

[Releases](../../releases)에서 `gats_wecat4_vial.bin`(일반) 또는 `gats_wecat4_dogakey.bin`(dogakey 버전)을 받습니다. 무선을 쓰지 않는다면 `gats_wecat4_vial_wired.bin`도 됩니다.
받은 파일은 Releases에 적힌 sha256 값과 같은지 확인하세요.

**부트로더 진입**: 케이블을 뺀 상태에서 스위치를 유선에 두고, **Tab 키를 누른 채로** 케이블을 꽂습니다. 키보드가 `342D:DFA0`(WB Device in DFU Mode)으로 잡힙니다. 원래 펌웨어에서도 같은 방법으로 들어갑니다.
이 펌웨어에서는 이 방법으로 들어가면 키보드에 저장된 키 배치가 초기화됩니다.

**굽기 도구**: [wb32-dfu-updater](https://github.com/WestberryTech/wb32-dfu-updater)의 `wb32-dfu-updater_cli`를 씁니다. [QMK MSYS](https://msys.qmk.fm/)(Windows)나 QMK CLI(macOS·Linux)를 설치하면 함께 설치됩니다.

```bash
wb32-dfu-updater_cli -s 0x08000000 -D gats_wecat4_vial.bin
```

끝나면 케이블을 다시 꽂거나 `wb32-dfu-updater_cli -R`로 재시작합니다.
Windows에서 장치를 못 찾으면 [Zadig](https://zadig.akeo.ie/)으로 `342D:DFA0`에 WinUSB 드라이버를 설치하세요.

## 직접 빌드하기

[vial-qmk](https://github.com/vial-kb/vial-qmk)와 QMK 빌드 환경이 필요합니다. 검증한 vial-qmk 커밋은 `dd43959ae5c08d8a28d38a1acf7b04e86b14a344`입니다.

```bash
git clone https://github.com/vial-kb/vial-qmk.git
git -C vial-qmk checkout dd43959ae5c08d8a28d38a1acf7b04e86b14a344
git -C vial-qmk submodule update --init --recursive
QMK_HOME=$PWD/vial-qmk ./scripts/build.sh vial
```

- `scripts/build.sh vial`: 무선 포함. 제조사 무선 라이브러리를 `scripts/fetch_libmodule.sh`가 제조사 저장소에서 받아 sha256을 확인한 뒤 빌드합니다.
- `scripts/build.sh dogakey`: 무선 포함 dogakey 버전(상태 강조·언어 전환 번쩍임·eager 디바운스).
- `scripts/build.sh vial_wired`: 유선 전용. 제조사 바이너리 없이 GPL 소스만으로 빌드됩니다.
- 결과물은 `build/`에 생깁니다.
- 무선 상태 진단 빌드: `scripts/build.sh vial -e WECAT4_DIAG=yes`. 무선 모드에서도 USB를 유지하고, raw HID 명령 `0xD1`로 상태를 읽을 수 있습니다.

## 하드웨어 정보

| 항목 | 값 |
|---|---|
| MCU | WB32FQ95RCT6(Cortex-M3), 외부 12MHz 크리스털 |
| 매트릭스 | 4×12, ROW2COL. 열 `C0 C1 C2 C3 A6 B10 B11 B12 B13 B14 A10 C6`, 행 `A2 A3 A4 C13` |
| LED | WS2812 47개(B15), 전원 제어 A5·A9 |
| 무선 칩 연결 | UART3 C10(TX)/C11(RX) |
| 모드 스위치 | C14/C15(풀업) |
| USB | VID `0x342D`, PID `0xE47E`(원래 펌웨어와 같음) |
