# 배포 전 실기 확인 목록

무선 포함 빌드(`gats_wecat4_vial.bin`)를 실제 키보드에 넣고 확인한다. 확인 못 한 항목은 README 기능 표에 ⚠️로 남긴다.

| # | 항목 | 방법 | 결과 |
|---|---|---|---|
| 1 | 굽기·재시작 | Tab 누른 채 연결 → `wb32-dfu-updater_cli -s 0x08000000 -D` → `-R` → USB `wecat4` 로 다시 잡힘 | |
| 2 | 기본 레이어 44키 | 키 입력 확인(각인과 같은지) | |
| 3 | Fn 레이어 | 숫자·`-`·`=`·`` ` ``·Esc·방향키 | |
| 4 | 조명 키 | Fn+Z 효과, X/C 속도, B/M 색상, N/H 밝기, J/G 채도 | |
| 5 | Win 잠금 | Fn+Win 후 Win 키 무시, 다시 누르면 복귀 | |
| 6 | Vial 접속 | 유선에서 Vial 이 정의 파일 없이 키보드를 인식, 키 변경이 즉시 반영·재연결 후 유지 | |
| 7 | Vial 잠금 해제 | Tab+Backspace | |
| 8 | 블루투스 | 스위치 BT, Fn+A/S/D 3초 페어링 → 짧게 전환, 연결 표시(깜박임·10초 경고·연결 완료) | |
| 9 | 2.4G | 동글 꽂고 스위치 2.4G, Fn+F 3초 페어링, 입력 | |
| 10 | 배터리 표시 | 무선 모드 Fn+Backspace → Q~P 불빛 | |
| 11 | 충전 표시 | 케이블 연결 상태 Fn+오른쪽 Space → 빨강/초록. 완충 핀 A15 는 다른 보드 값이라 특히 확인 | |
| 12 | 초절전 | 무선 Fn+Enter → 조명 꺼짐·아무 키로 복귀 / 유선 → 조명 끔 | |
| 13 | 공장 초기화 | Fn+왼쪽 Ctrl 3초 → 재시작·Vial 변경 내용 초기화 | |
| 14 | 5분 백라이트 끔 | 5분 무입력 | |
| 15 | 30분 수면 | 무선 30분 무입력 → 연결 해제 → 아무 키로 재연결 | |
| 16 | 저배터리 표시 | 잔량 20% 이하에서 Fn 키 빨강 깜박임 | |
| 17 | 유선 전용 빌드 | `gats_wecat4_vial_wired.bin` 굽기 → 입력·조명·Vial·Fn+LCtrl 초기화 | |
| 18 | dogakey 상태 강조 | `gats_wecat4_dogakey.bin` 굽기 → Fn·Shift·Ctrl·Win 누르는 동안 해당 키만 켜짐, 색 표와 같은지 | |
| 19 | dogakey 언어 전환 번쩍임 | CapsLock·오른쪽 Alt → 초록 밝아짐 → 하늘색 띠 좌→우 → 원래 조명 | |
| 20 | dogakey 무선 | 블루투스에서 입력·연결 표시가 일반 버전과 같은지 | |
